# Haunted House

A small 3D stealth game built with **Unity and C#**. Navigate through a haunted house, avoid enemies, collect the key, and find your way to the exit without getting caught.

## 🎮 Play Online

You can play the WebGL version directly in your browser:

👉 **[Play Haunted House](https://haunted-house.tobias-illner.de/)**

## 🕹️ Gameplay

- Explore the haunted house
- Avoid patrolling enemies
- Stay out of enemy detection zones
- Find and collect the key
- Unlock the door
- Reach the exit as quickly as possible

## 🛠️ Built With

- Unity
- C#
- Unity UI Toolkit
- Unity WebGL

## 📚 About the Project

This project was created while following the **Unity Learn – 3D Stealth Game: Haunted House** course.

The project helped me practice working with player movement, enemy behavior, collision and trigger systems, UI, audio, scene management, and WebGL deployment.

I also implemented and customized additional features such as a **game timer, key and door mechanics, restart functionality, and UI adjustments**.
